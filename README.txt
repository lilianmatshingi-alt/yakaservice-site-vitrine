YAKA — Site vitrine
===================

Contenu :
- index.html : structure du site
- style.css : identité visuelle responsive (violet, crème, accents vert clair)
- script.js : menu mobile et année automatique

Aperçu local :
1. Décompressez le dossier.
2. Ouvrez index.html dans un navigateur.

Mise en ligne :
- Déposez les trois fichiers sur votre hébergeur statique, ou importez-les dans un dépôt GitHub puis connectez ce dépôt à Render.
- Le site renvoie vers l'application existante : https://yaka-artisan.onrender.com

À personnaliser avant publication si nécessaire :
